# Networks and assets [Network capabilities and supported token types]

A **network** is a blockchain on which an account can operate. Splits groups networks by their supported capabilities.

Owners control active networks in [Settings > Networks](https://app.splits.org/settings/team/networks/). [Settings](/teams/settings) describes access to this page.

**Balances appear only for active networks.** Any listed network can be active, regardless of its support group.

Accounts use the same address, signers, threshold, and owner across active networks. [Signer changes](/accounts/editing#change-signers-and-thresholds) cover those networks with one signature.

Splits applies account state to a newly active network before account use there. Network deactivation requires no onchain transaction.

Email support to request another network or asset type. Additional network support depends on Splits' providers.

## Fully supported networks

These networks support balances, transactions, swaps, transfers across networks, and accounting:

- Ethereum Mainnet
- Base
- Optimism
- Arbitrum
- Celo
- World Chain
- Tempo
- Polygon (PoS)
- BNB Smart Chain
- HyperEVM

## Partially supported networks

These networks support balances, sends, swaps, and transfers across networks. **Transaction history and accounting are unavailable.** NFT management in this group works only on Zora and Robinhood Chain.

- Linea
- Zora
- Monad
- MegaETH
- Scroll
- Robinhood Chain

## Transfers to other networks

A [swap](/transactions/swaps) can send tokens to an external address on Solana or an EVM network supported by Relay.

[Relay's network reference](https://docs.relay.link/references/api/api_resources/supported-chains) lists destination support.

## Browser extension and WalletConnect

The [browser extension](/introduction/extension) and [WalletConnect](/integrations/walletconnect) work on any active network.

## Supported assets

Supported asset types include:

- Native tokens, such as ETH.
- ERC-20 tokens.
- ERC-721 tokens.
- ERC-1155 tokens.

NFT availability depends on the network's capabilities. If you send an unsupported asset to a Splits account, email support to investigate recovery.

## Programmatic access

Through the [Splits CLI / MCP](/introduction/agents):

- `splits chains list`: list networks, support groups, and capability flags (**Read** scope).
- `splits chains get --chainId 8453`: show one network (**Read** scope).

The endpoint is `GET /public/v1/chains`. It requires Read scope. The list excludes networks that still have a gradual release restriction.
