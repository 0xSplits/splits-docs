# Asset support

*Last updated 1 October 2025*

We currently support the following asset types:

- ERC-20
- ERC-721
- ERC-1155

All supported assets work on all supported networks. Check out the list [here](/getting-started/network-support).

Please reach out to request any additional asset types you need. We are open to supporting all asset types, pending support from our underlying providers. If you accidentally send an unsupported asset to a Splits account, let us know and we will attempt to recover it.
