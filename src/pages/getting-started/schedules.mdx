# Schedules

*Last updated 16 September 2025*

The *Schedules* page lets you create recurring transactions by specifying a future start date and an interval/frequency. This will create a transaction from a selected account on a set interval that pays out pre-defined amounts to multiple recipients. This can be used for payroll, topping up sub-accounts (e.g. "Eng testing" shared account), and diversifying assets.

![](/images/schedules/img-1.png)

Because your funds are self-custodied (i.e. we can't access them), you will still need to approve each transaction. You will be notified via email when a transaction is ready for your review. Emails are sent daily at 11:00 AM UTC.

![](/images/schedules/img-2.png)

You can edit, pause, or delete a schedule from the *Schedules* page.

![](/images/schedules/img-3.png)
