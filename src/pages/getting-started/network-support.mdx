# Network support

*Last updated 20 March 2026*

## Supported networks

| Network | Fully supported | Splits Connect |
| --- | --- | --- |
| Ethereum Mainnet | **✅** | **✅** |
| Base | **✅** | **✅** |
| Arbitrum | **✅** | **✅** |
| Optimism | **✅** | **✅** |
| Celo | **✅** | **✅** |
| World Chain | **✅** | |
| Tempo | **✅** | |

App support means the chain is fully supported on [app.splits.org](https://app.splits.org/).

Splits Connect support means the chain is fully supported in our [browser extension](https://chromewebstore.google.com/detail/splits/ghfacfafnbcgkielpaeifdpoggfeakif?pli=1). WalletConnect capability is still available in-app for these networks.

## Partially supported networks

| Network | Send | Asset recovery |
| --- | --- | --- |
| Linea | **✅** | **✅** |
| Polygon (PoS) | **✅** | **✅** |
| BNB Smart Chain | **✅** | **✅** |
| Zora | **✅** | **✅** |
| Solana | **✅** | |
| EVM [Relay networks](https://docs.relay.link/references/api/api_resources/supported-chains) | **✅** | |

Send support means you can bridge and send tokens to an external address on this chain.

Asset recovery support means that you can bridge tokens back to a fully supported network. Please reach out if you need asset recovery on additional networks.

## Request additional networks

Please reach out to request any additional networks you need. We are open to supporting all EVM-equivalent networks, pending support from our underlying providers.
