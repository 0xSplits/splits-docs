# Using Splits with splitter contracts

*Last updated 14 October 2025*

Splits ([app.splits.org](http://app.splits.org)) and Splits Explorer ([explorer.splits.org](http://explorer.splits.org)) are two separate apps. We intend to bring some of the core Explorer functionality into Splits over time, but in the meantime you can use the two together by connecting a Splits wallet to the Explorer.

![](/images/using-splits-with-splitter-contracts/img-1.png)

[Here is a video](https://ro.am/share/dbcmq1qc-urs56zrn-0g5puw0o-yf9hfiw4) of Abram using a Splits account to create a Split, send funds to the Split, and then distribute funds to the recipients.

See [Using WalletConnect](https://app.notion.com/p/279f7c3c8eff80378c01f9d1056ca1fa) for more details on how to use a Splits account on third party apps.
