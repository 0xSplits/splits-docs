# Batch swapping long-tail tokens

*Last updated 14 November 2025*

You can save time and operational complexity by having multi-token revenue streams (e.g. swap fees) route through a [Swapper contract](https://docs.splits.org/core/swapper) controlled by a Splits account. Periodically, anyone who is a signer on the controlling account can go through and swap all the tokens into the output token (i.e. USDC) in a single transaction. This will reduce the number of tokens and transactions that hit your accounts.

## Use a dedicated operating account

As a general practice, we like to keep "operating" and "value accrual" accounts separate. You can either create a dedicated operating account for this purpose, or use an existing one you already have set up.

In the left nav, click the plus icon to create a new account, give it a name, choose the signers, and set the threshold. We recommend only requiring 1 approval for transactions, since that will make processing the tokens in Swapper easier.

![](/images/batch-swapping-long-tail-tokens/img-1.png)

## Create a Swapper

Go to app.splits.org, select *New contract*, specify the (1) network (most likely Base), and then select (2) *Swapper*. This will bring you to the new Swapper form.

![](/images/batch-swapping-long-tail-tokens/img-2.png)

Specify the (1) output token (i.e. USDC), set the (2) beneficiary to be the destination address for the swapped tokens (e.g. Treasury or any "value accrual" account), and set the (3) owner to be your operating account.

![](/images/batch-swapping-long-tail-tokens/img-3.png)

You can use [Splits Connect](/getting-started/connecting-to-other-apps) to connect using your operating account and create the Swapper.

## Batch process Swapper tokens

Once tokens have accumulated in the Swapper, you can batch process them by (1) selecting the tokens you wish to swap, and (2) hitting *Swap*.

![](/images/batch-swapping-long-tail-tokens/img-4.png)

Make sure you are connected using the Swapper's owner—you will see a message saying, "You control this Swapper".

![](/images/batch-swapping-long-tail-tokens/img-5.png)

Once you execute that transaction, all selected tokens will be swapped into the output token and sent to the beneficiary.
