# Repaying loans from Clanker fees

*Last updated 10 November 2025*

We're seeing some teams borrow against future earnings generated by their Clanker tokens. In this guide, we'll go through how to set up a system to transparently repay lenders.

## Create a Token Ops subaccount

For simplicity the first thing we'll do is create a dedicated subaccount for this purpose. We'll call it Token Ops, and I'll add myself and my cofounder as signers. We'll set the threshold to 1, so that either of us an execute transactions.

![](/images/repaying-loans-from-clanker-fees/img-1.png)

We strongly recommend using [Splits Connect](/getting-started/connecting-to-other-apps) to use your subaccount on other apps, since WalletConnect is unreliable.

## Create a Waterfall

Waterfall allows you to specify the order in which payouts occur. For our purposes, we're going to use USDC as the target token, and have 2 tranches of $20k USDC each (because we borrowed $40k total from 2 different lenders). [Create a Waterfall here](https://app.splits.org/new/waterfall/?chainId=8453).

![](/images/repaying-loans-from-clanker-fees/img-2.png)

Tranche 1 will be paid first, then tranche 2 (and so on), until all residual funds will be paid out to the residual tranche.

![](/images/repaying-loans-from-clanker-fees/img-3.png)

With the Waterfall set up ([here is the one used in the above example](https://app.splits.org/accounts/0xa00145c19fcCBd0438eD90CEB79e7d55082B6117/?chainId=8453)), we now need to set up a Swapper to automatically swap the WETH Clanker fees into USDC, and then send to the Waterfall.

## Create a WETH → USDC Swapper

Since we intend to repay this loan using USDC and Clanker fees are earned in WETH, we'll create a Swapper to convert WETH into USDC before sending to the Waterfall. [Create a Swapper here](https://app.splits.org/new/swapper/?chainId=8453).

Output token is USDC, the Beneficiary is the address of the Waterfall we just created, and the Owner is the Token Ops subaccount.

![](/images/repaying-loans-from-clanker-fees/img-4.png)

Now, when WETH is sent to the Swapper, they'll get converted into USDC and sent to the Waterfall, which will ensure each tranche recipient is paid according to the schedule we just set. Note that if you are processing a lot of volume on an L2, you will want to use a smaller default discount incentive in *Advanced settings*.

![](/images/repaying-loans-from-clanker-fees/img-5.png)

[Here is the Swapper from the above example](https://app.splits.org/accounts/0xaB0567b2cCfBf46ecC9a9eBF364C9cC25A964aaE/?chainId=8453).

## Configuring your Clanker

When setting up your Clanker token, in the Rewards Recipients setction:

1. Set the Token Ops subaccount as the Admin Address
2. Set the Swapper as the Reward Recipien Address
3. Select WETH as the Reward Token

![](/images/repaying-loans-from-clanker-fees/img-6.png)

Deploy your Clanker.

## Process Clanker fees

On some cadence, you can use your Token Ops subaccount to connect to Clanker and withdraw your fees. Doing so will move the WETH from the Clanker contract to the Swapper contract.

Once WETH is in the Swapper contract, open the Swapper page, select the WETH balance and click Distribute. This will convert the WETH into USDC and send it to the Waterfall.

Once the USDC is in the Waterfall, open the Waterfall page, select the USDC balance and click Distribute.

Continue this process until the $40k has been repaid and all the non-residual tranches are complete.

## Update the Clanker Reward Recipient

Once all tranches are repaid and you have returned the $40k, you can replace your Clanker's Reward Recipient from the Swapper to the Token Ops account. This way, the WETH fees will be collected directly into your Token Ops account instead of having to route it through the Swapper and Waterfall contracts.
