# Batch [Group transactions for a signature]

A **batch** groups multiple transactions for execution. A signer signs the batch once.

**Each team can have only one active batch on one account and network.** Other accounts and networks cannot add transactions to that batch. A batch holds up to 50 transactions.

1. Prepare a transaction.
2. In the review dialog, select *Add to batch*.
3. Repeat for other transactions on the same account and network.
4. Open the batch above the transaction feed.
5. Inspect each transaction's calls and simulation.
6. Remove any unwanted transactions.
7. Submit the batch.
8. Sign the batch.

<a id="batching-from-external-apps" />

## Batches from external apps

The [browser extension](/introduction/extension) and [WalletConnect](/integrations/walletconnect) also show *Add to batch* for transactions from other apps.

The other app might not show the transaction as pending until the batch executes.
