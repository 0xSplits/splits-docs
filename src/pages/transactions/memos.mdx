# Memos [Add transaction notes for accounting records]

A **memo** is a short note on a transaction. Memos appear with transactions in the app and in CSV exports. [Accounting](/accounting) can filter transactions by memo.

<a id="adding-a-memo" />

## Add a memo

Any member can add or edit a memo. A new transaction form accepts a memo.

For an existing inbound or outbound transaction:

1. Open the transaction's row menu.
2. Select *Add memo*.
3. Enter the memo.

<a id="requiring-memos" />

## Require memos

The *Require memos* [team setting](/teams/settings) rejects new transactions without memos. It applies to the app, [CLI and MCP](/introduction/agents), and [schedules](/transactions/schedules).

The check applies at creation. Memos on existing transactions remain editable.

## Programmatic access

Through the [Splits CLI / MCP](/introduction/agents):

- `splits transactions memo <id> --memo "text"`: set or clear a memo, with a maximum of 500 characters (**Write** scope).
- `splits transactions properties set <id> --properties '{"k":"v"}'`: set structured transaction properties (**Write** scope).

[Transaction metadata](/introduction/agents#transaction-metadata) describes property limits.
