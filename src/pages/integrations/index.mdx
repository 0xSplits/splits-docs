# Integrations [Connect Splits accounts to other services]

An **integration** connects Splits to another app or protocol.

The [browser extension](/introduction/extension) and [WalletConnect](/integrations/walletconnect) connect accounts to other apps. The [CLI and MCP](/introduction/agents) provide access for agents and scripts.

| Integration | Function |
| --- | --- |
| [Bankr](/integrations/bankr) | Account operations through an agent |
| [Clanker](/integrations/clanker) | Token reward claims |
| [ENS](/integrations/ens) | Names for account addresses |
| [Farcaster](/integrations/farcaster) | Address verification, recovery, and storage payments |
| [Hedgey](/integrations/hedgey) | Vesting and lockup claims |
| [Rain](/integrations/rain) | Card collateral and payment records |
| [Sablier](/integrations/sablier) | Vesting claims |
| [Uniswap](/integrations/uniswap) | Liquidity position fee claims |
| WalletConnect | Account connections |

## Positions

A **position** is an account's balance or claim in an external protocol. The *Positions* section on an account page shows supported positions beside token balances.

Supported positions include vesting streams, lockup plans, and liquidity provider rewards.

A claim transfers available tokens to the account. It follows the normal [transaction](/transactions) approval process at the account's [threshold](/accounts/thresholds).

If the protocol charges a claim fee, the claim dialog shows it. **The account needs enough of the fee token to claim.**

Email support to request another protocol.
