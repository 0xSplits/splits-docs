# Bankr [Use a Bankr agent with Splits]

**[Bankr](https://bankr.bot)** is an AI agent with a trading wallet. It can operate Splits through the [CLI and MCP](/introduction/agents).

The [Bankr Splits skill](https://github.com/BankrBot/skills/tree/main/splits) describes setup, commands, and key protection.

## Access paths

A Bankr agent can use an account as a signer or through a module:

| Property | Signer | Module |
| --- | --- | --- |
| Signing key | Registered EOA | Bankr wallet |
| Execution | Proposal and signatures | Direct calls |
| Approval policy | Account threshold | Module authority |
| Removal | Signer removal | Module removal |

[Signing keys](/members/keys#eoas) describes EOA registration. [Modules](/accounts/modules) describes direct execution authority.

With a 2-of-n [threshold](/accounts/thresholds), an agent with one signer needs another signer's approval. **A threshold alone does not guarantee human approval.** The other signing keys must remain under human control for that policy.

A 1-of-n account permits the agent to execute alone. An [operating account](/accounts#operating-accounts) with a limited balance can limit its direct funds access.

A module can also call contracts that check `msg.sender`. **A module does not need approval for each action.** Its authority can include external contracts on which the account has permissions.

## Setup

Prerequisites: an Owner must create the API key and approve account signer changes.

1. Create an API key in [Settings > API Keys](https://app.splits.org/settings/team/api-keys/).
2. Give it the Owner scope if the agent needs account creation or signer change proposals.
3. Install the Bankr Splits skill.
4. Follow the skill to register the agent's EOA.
5. Create an account or propose a signer change with the intended human and agent signers.
6. Approve the signer configuration in the app.

Proposals appear in the transaction feed. Module calls have onchain events and feed records.

## Programmatic access

Through the [Splits CLI / MCP](/introduction/agents):

- `splits auth login`: configure the API key.
- `splits auth create-key --register`: create and register the agent's signing EOA.

The Bankr skill describes the remaining commands.
