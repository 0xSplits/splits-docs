# Sablier [View and claim vesting tokens]

**[Sablier](https://sablier.com)** provides token vesting streams. Streams from v2 and v3 that pay a Splits account appear as [positions](/integrations#positions).

Each position shows the amount available to claim. If the stream has a cliff, it also shows the first release date.

A claim transfers available tokens into the account. **Sablier v3 charges a fee for each claim.** The dialog shows the fee, and the account needs enough ETH to pay it.

Each position links to the stream on Sablier.
